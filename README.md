# ocr-md

Utilitaire de bureau (macOS et Windows) qui rend lisibles les PDF scannés avec le moteur OCR du système et produit, pour chaque pièce, un PDF consultable et un Markdown annoté destiné à l'analyse par IA. Projet du GIE NOVEA, en cours de développement (version 1 en préparation).

- Spécification : `docs/cahier-des-charges.md` ; plan : `docs/plan-v1.md` ; avancement : `docs/avancement.md`.
- Installation et usage : guides à venir (jalons 9 et 10).
- Développement : `uv sync` puis `uv run pytest`.
